# STREZO help

Condensed from STREZO_USER_GUIDE.md. Uppercase headings and paragraphs below
are the built-in content; keep this summary synchronized with the user guide.
The screen supports letters, digits, spaces and periods. Use short complete
sentences rather than punctuation that the font cannot display.

<!-- HELP START -->
QUICK START

Use INPUT to assign audio to LEFT and RIGHT. Shape the ten band levels on BANK. Assign bands to groups on GROUPS. Route groups to outputs on OUTPUT.

CONTROLS

Turn to select a control. Click to edit it. Turn to adjust it. Click again to finish. Use PAGE to change pages. Use SCROLL to read this help.

BANK AND BANDS

Band levels are bipolar. The center is zero. PRESET recalls levels. DRIVE sets input strength. RESONANCE extends ringing. Use BANDS to enable and tune bands. Motion varies their frequencies.

INPUT AND METERS

Set audio VALUE to zero to mute. Its tick marks unity gain. CV VALUE selects the target. DEPTH sets amount and polarity. Bottom meters show input mixes before DRIVE and feedback. 0 DB means a 5 V peak. Accent lamps show clipping.

GROUPS AND FEEDBACK

Bands can feed several groups. Use FEEDBACK to select bands for the loop. KNEE sets where soft limiting starts. CEILING sets its limit. DAMPING reduces resonance as feedback rises. Lower FEEDBACK or DRIVE to tame overload.

CROSS

SAME returns feedback to the same side. CROSS sends it to the other side. Layouts and sends route feedback between groups. Choose LINEAR or FINE on OPTIONS to change the CROSS response.

OUTPUT AND STEREO IMAGE

Each output mixes G1 through G4 and DRY from its LEFT or RIGHT side. MID sets center gain. SIDE adjusts stereo width. 64 gives unity gain. 128 gives twice unity gain. These controls affect wet output only and do not change feedback. DRY bypasses them.

OPTIONS

PALETTE sets colors. ROW DRY decides if output row edits also change DRY. SAVE DEFAULT stores this setup in the current slot. HELP does not change the sound.
