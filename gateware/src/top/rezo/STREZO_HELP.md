# STREZO help

Condensed from STREZO_USER_GUIDE.md. Uppercase headings and paragraphs below
are the built-in content; keep this summary synchronized with the user guide.

<!-- HELP START -->
QUICK START

INPUT: assign LEFT and RIGHT audio. BANK: shape the ten bands. GROUPS: assign wet bands to busses. OUTPUT: route those groups to outputs.

CONTROLS

Turn to select, click to edit, turn to adjust, click to finish. On HELP, PAGE changes views and SCROLL moves through this text.

BANK AND BANDS

Band levels are bipolar; center is zero. PRESET recalls a shape. DRIVE excites the bank and RESONANCE extends ringing. BANDS enables bands and sets frequencies. Motion source, rate, phase and depth vary frequency.

INPUT AND METERS

VALUE fully down mutes; the tick marks unity gain. CV selects a destination; DEPTH sets strength and polarity. Bottom input meters show the mix before DRIVE and feedback. 0 DB is 5 V peak. Accent lamps show clipping.

GROUPS AND FEEDBACK

Each band can join several groups. Feedback taps return enabled band signals to the bank. KNEE starts soft limiting; CEILING sets its final limit. DAMP restrains resonance as feedback rises. Reduce feedback, DRIVE or resonance to recover from extreme overload.

CROSS

SAME returns each side to itself. CROSS returns the opposite side. Layouts and matrix sends choose which groups interact. LINEAR and FINE change CROSS control travel.

OUTPUT AND MID/SIDE

Route G1 to G4 and DRY to each output; select LEFT or RIGHT. MID boosts shared center content; SIDE changes width. 64 is unity, 128 is twice gain. MID/SIDE follow feedback taps and affect only wet output. DRY bypasses them.

OPTIONS

Choose PALETTE and ROW DRY, then SAVE DEFAULT. ROW DRY includes or excludes DRY from whole-row output edits. Saved settings belong to this slot. HELP does not change the sound.
