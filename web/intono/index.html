Connection & workflow

Use a desktop browser with Web Serial, such as Chrome or Edge, over localhost or HTTPS. Choose Tiliqua’s USB debug serial port, then launch INTONO from the factory bootloader. Close other serial monitors first.

Stop calibration, all running routes, and Reference CV before reading or writing. Read creates a local snapshot of all sixteen slots. Local edits are not saved to the instrument until you write a slot. Export library creates a backup file; importing one changes the local snapshot only.

Calibration edits change the stored name while preserving the measured curve and quality data. Scales store interval choices across 1–8 octaves, without a root key. USB is used for this utility’s serial connection; musical MIDI input remains the 3.5 mm jack.
