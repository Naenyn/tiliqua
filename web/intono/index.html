Scala import preserves microtonal intervals and non-octave periods to 0.001 cent. Scala files: maximum 100,000 bytes, 1–128 pitches including the final repeating period, and a period up to 9600 cents (eight octaves). Pitches must be positive and strictly ascending after rounding. Connection & workflow

Use a desktop browser with Web Serial, such as Chrome or Edge, over localhost or HTTPS. Choose “Tiliqua R5 apfbug…” (the USB debug serial port), then launch INTONO from the factory bootloader. Close other serial monitors first.

Stop calibration, all running routes, and Reference CV before reading or writing. Read creates a local snapshot of all 24 slots. Local edits are not saved to the instrument until you write a slot or use Write changes to device. Bulk writes review changed slots across all three tabs, verify each slot, and stop on an error. Empty slots never delete device profiles. Apply any interval text edits before writing. Export library creates a backup file; importing one changes the local snapshot only.

Gold markers and “Not written to device” mean edits exist only in this browser. Tab counts and the banner include changes across all three banks. Exporting saves a file and leaves these markers active; verified device writes clear them. Keep the tab open until you write or export changes you want to keep.

Calibration edits change the stored name while preserving the measured curve and quality data. Scales store interval choices across 1–8 octaves, without a root key. USB is used for this utility’s serial connection; musical MIDI input remains the 3.5 mm jack.
